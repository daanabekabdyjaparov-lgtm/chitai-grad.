# Читай-Град — книжный магазин

Учебный веб-проект книжного магазина «Читай-Град». Сайт знакомит посетителей с каталогом книг, бестселлерами, новостями и книжным клубом.

## Возможности

- Адаптивная главная страница в уютном книжном стиле.
- Каталог книг с поиском по названию и автору.
- Фильтрация художественной и учебной литературы.
- Интерактивный блок с эффектом перелистывания страниц.
- Раздел новостей и информация о книжном клубе.
- Ссылки навигации по разделам сайта.

## Технологии

- HTML5
- CSS3
- JavaScript (без дополнительных библиотек)

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

Для локальной разработки можно открыть папку проекта в Visual Studio Code и воспользоваться расширением Live Server.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в него файлы проекта.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Через некоторое время GitHub Pages покажет ссылку на опубликованный сайт.

## Примечание

Проект является демонстрационным шаблоном. Названия книг, цены, новости, адрес электронной почты и количество участников клуба приведены как пример и могут быть заменены на реальные данные.
